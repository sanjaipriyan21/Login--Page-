🔐 Login Page Design

📌 Project Overview

This project is a simple, creative, and responsive Login Page designed using HTML and CSS. It provides a clean and attractive user interface for users to enter their login details.

🎯 Objectives

- Create an attractive login page.
- Design a clean and user-friendly interface.
- Include email and password fields.
- Add a login button.
- Make the page responsive for mobile and desktop devices.

🛠️ Technologies Used

- HTML5 – To create the structure of the login page.
- CSS3 – To style the page and make it responsive.

✨ Features

- Modern and clean design.
- Email input field.
- Password input field.
- Login button.
- Responsive layout.
- User-friendly interface.

📂 Project Structure

Login-Page-Design/
│
├── index.html
├── style.css
└── README.md

🚀 How to Run the Project

1. Download or clone this repository.
2. Open the project folder in Visual Studio Code.
3. Open the "index.html" file.
4. Run the file using Live Server or your browser.
5. Explore the Login Page.
